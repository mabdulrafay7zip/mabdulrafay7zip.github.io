About — My Short Story

Every developer has
an origin story.

Mine starts with a falling block, a blank screen — and the question “what if the machine could learn?”

01

The First Build

Before the models and the metrics, there was a game. As a new BS Artificial Intelligence student at Air University, Islamabad, I built a complete Tetris clone in C++ — game loop, scoring, levels, all of it. The first time I took a program from an empty file to something people could actually play, and I was hooked on finishing things.

02

Machines That Learn

Then came the real fascination: software that improves itself. I moved from writing rules to training models — first prediction models with scikit-learn, then recommendation engines, classifiers and clustering systems on real datasets. An 8,790-title Netflix dataset taught me more about messy, real-world data than any textbook could.

03

Learning in the Field

Through three Machine Learning internships, I worked as a Machine Learning Intern on production-style problems: cleaning data, engineering features, comparing algorithms and defending the results. My best model reached 97.5% accuracy — and the habit of measuring everything stayed with me.

04

The Next Page

Today I’m going deeper into Deep Learning and NLP, shipping open-source projects and a live ML demo anyone can try. The story is still being written — and I’m open to remote AI/ML internships worldwide for the next chapter.
